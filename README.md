# Bubble Builds

Build appearance presets for Creative Destruction, with Apply and Restore Backup.

[Download the Windows app](https://github.com/samimustafaa/bubble-builds-cd/releases/latest)

Close the game, select its folder, choose a preset, then Apply. The gallery includes **Bubble Wrap TEST 01**, **Mobile / flat**, and all ten smooth concepts: Ceramic, Obsidian, Silver, Aqua, Mint, Opal, Terracotta, Slate, Champagne and Ink Porcelain.

The ten new materials have an **Animated surface effects** switch. These are looping shader highlights/colour effects; the game's build assembly is unchanged. Thumbnails are concept references, not verified gameplay. Materials are experimental and need an in-game test.

**Restore backup** returns the exact pre-first-Apply files. **Updates → Check now → Update & restart** downloads, installs and reopens the app. Backups remain outside the installation.

Patches are generated locally from supported game files. No game archives or custom-image uploads are included.
