# Bubble Builds

Original Bubble Wrap plus five bubble variants for Creative Destruction: Pearl, Ice, Frost, Lilac and Aqua.

[Download the Windows installer](https://github.com/samimustafaa/bubble-builds-cd/releases/latest)

Close the game, choose its folder, select a bubble preset and click **Apply**. **Restore backup** restores the exact files saved before the first Apply. **Updates → Check now → Update & restart** installs the latest app automatically; backups stay outside the installation.

The original preset is unchanged. New variants preserve underlying shading, use mesh UVs and soften bubble edges. Samples are offline UV material renders from the shader equations, not gameplay screenshots. Lighting, texture scale and appearance must be checked in-game; no exact match to the earlier AI concept art is claimed. Build geometry and assembly animations remain the game's own.

Patches are generated locally from supported original game files. No game archives are distributed.
