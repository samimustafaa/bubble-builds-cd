# Bubble Builds

20 build appearance presets for Creative Destruction, with Apply and Restore Backup.

[Download the Windows installer](https://github.com/samimustafaa/bubble-builds-cd/releases/latest)

Close the game, choose its folder, select a preset and click Apply. Use **Show** to filter Lightweight, Smooth or Patterned. Surface animation can be switched off for animated materials.

Includes Bubble Wrap, Mobile / flat, the ten smooth materials, Toon Timber, Blueprint, Kintsugi, Redline Carbon, Aurora Flow, Porcelain Checker, Low Detail and Ultra Light. The two lightweight variants omit added animated sheen; FPS gains have not been benchmarked.

**Restore backup** returns the exact files saved before the first Apply. **Updates → Check now → Update & restart** downloads, installs and reopens automatically. Backups stay outside the installation.

Materials are experimental approximations. Preview pictures and material samples are illustrative. Existing build geometry and assembly motion remain. Patches are generated locally from supported game files; no game archives are distributed.
