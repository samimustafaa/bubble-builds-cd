# Verification — 0.1.10

- Ten selectable presets: original Bubble Wrap, five bubble variants and four authored wood tests. Existing six preset resource hashes are preserved.
- The wood shader reuses `diffuse_instensty`, a float already declared in both supplied original HLSL build shaders. The custom `sgBuildVariant` declaration and material tag are removed. Missing known shader bindings are rejected rather than introducing an unregistered uniform.
- Supported structure materials set the known parameter to the authored marker. Ten existing numeric values are replaced without duplicating the node; 308 materials receive the known parameter. All other typed values and tree structure are preserved. BXML header size and attribute-table offsets are recalculated.
- Apply records the patch version. A prior or legacy game-file patch produces an Apply-again notice after an app update. Restore clears the applied version while keeping the first backup intact.
- The four plank masks have permanent gaps independent of construction progress, frame strips and optional diagonal braces. Pixel discard affects visible surfaces, not collision geometry. No stage lock or model replacement is claimed. Alpha and existing assembly animation remain otherwise unchanged.
- Previews come from `tools/render-timber-samples.cjs`, using matching plank masks, grain and color equations under fixed assumed lighting. Cutouts are represented by transparent pixels. They cannot demonstrate the game's UVs, lighting, shadows or material parameter binding.
- Unit tests check legacy backup version tracking, existing int/float binding replacement, missing-binding rejection, material offsets and retained values, parameter gating, permanent cutouts, frame continuity and distinct gap coverage. Windows tests compile 60 Direct3D 9 fixtures and exercise ten loaded previews, wood filtering, static motion controls, Apply, Restore, Updates and compact layout.
- Local verification decodes both supplied archives for all 20 preset/motion modes and checks resource counts, round trips and semantic digests. All supported structure material hierarchies and values are compared before and after tagging. Private game-file copies are patched, switched and restored byte-for-byte.

The reported failure in 0.1.9 is consistent with the custom parameter not being bound, but the cause cannot be confirmed in this environment. Gameplay acceptance and actual visual quality of 0.1.10 still require testing in Creative Destruction. The texture patches cannot duplicate Fortnite's individual plank geometry, and cutout shadows may not match the openings.
