# Bubble Builds

Build appearance presets for Creative Destruction, with Apply and Restore Backup.

[Download the Windows app](https://github.com/samimustafaa/bubble-builds-cd/releases/latest)

Close the game, choose its folder, then pick **Bubble Wrap — TEST 01** or **Mobile / flat**. Click Apply. **Restore backup** returns your exact pre-first-Apply files.

Custom Image has been removed. If an image is still applied in the game, select either remaining preset and click Apply to replace it.

Use **Updates → Check now → Update & restart** to download, install and reopen automatically. Backups stay outside the installation. Patches are generated locally from the supported game archives; no game archives are distributed.

New material and animation concepts shown in chat are previews for selection, not implemented presets.
